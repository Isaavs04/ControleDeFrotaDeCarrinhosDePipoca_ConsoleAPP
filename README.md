# ControleDeFrotaDeCarrinhosDePipoca_ConsoleAPP
Aplicativo do Console, feito para gerir uma frota de 20 carrinhos de pipoca, que vendem pipoca doce e salgada 

## ✦ Sobre
Projeto realizado em sala de aula para a matéria de programação estruturada do curso Análise e Desenvolvimento de Sistemas

## ✦ Funcionalidades
- [x] Vendas de pipoca doce e salgada para qualquer um dos 20 carrinhos de pipoca da frota.
- [x] Ver tabela de carrinhos com: ganhos e lucro total.
- [x] Ver carrinho com maior lucro.
- [x] Ver carrinho com menor lucro(carros sem lucro não são contados).
- [x] Sair do Console.
